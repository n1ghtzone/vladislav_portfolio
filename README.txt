ЛИЧНОЕ ПОРТФОЛИО ВЛАДИСЛАВА

Содержимое:
- index.html — главная страница сайта
- assets/ — фотографии, скриншоты статистики и дизайн-макеты

Как открыть:
1. Распакуйте архив целиком.
2. Откройте index.html в современном браузере.

Как опубликовать в интернете:
Загрузите все содержимое папки (index.html и папку assets) на статический хостинг, например GitHub Pages, Netlify или ваш веб-хостинг. Не загружайте только index.html отдельно: изображения подключены из assets/.
